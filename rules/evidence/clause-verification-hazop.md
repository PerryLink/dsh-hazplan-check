# 条文核查报告 —— dsh-hazplan-check：GB/T 35320—2017 全文核对与**严重级更正**

- **核查日期**：2026-10-07
- **核查方法**：取得标准公开全文，逐条比对规则 `basis` 的 `clause` 与 `excerpt`，
  **并核对每条所引条款的规范语气（应／宜）**。
- **结论**：**全文取得**。**引文本身全部逐字命中**，但 ⚠️ **本轮发现并更正了一处性质更严重的问题：
  两条 error 级规则所引条款用的是「宜」而不是「应」，而该标准是推荐性国家标准** —— 见第一节。

---

## 一、⚠️⚠️ 本轮最重要的更正：**两条 error 级规则不成立，已降为 warn**

### 问题

`dsh-hazplan-check` 原先有 **2 条 `error` 规则**，其规则库头部并明确声称：

> 「**可 error 的只有 6.6.3 与 6.6.4 这两类硬要求**（逐条记录、节点清单与未分析理由）。」

本次逐字核对后，**这个"硬要求"的定性不成立**：

| 规则 | 所引条款 | **该条款的逐字原文** | 语气 |
|---|---|---|---|
| `HZ-001` | 6.6.4 | 「每一个危险和可操作性问题都**宜**作为单项记录；」 | **宜** |
| `HZ-002` | 6.6.3 | 「HAZOP 分析输出**宜**包括：」 | **宜** |
| — | 6.6.4 引言 | 「报告信息**宜**符合以下要求：」 | **宜** |

**并且**：**GB/T 35320—2017 是推荐性国家标准**（标准号带 **"/T"**）。

⇒ **用"宜"的推荐性条款不能支撑 `error` 级判定。** 这正是本项目一贯的口径
（见 `dsh-power-ticket-check` 对 GB 26860—2011 **推荐性第 5 章**的处理、
`dsh-gongwen-word-check` 对 **GB/T 9704—2012** 的处理）。

### 已做的更正

| 项 | 改动 |
|---|---|
| `HZ-001` | `severity: error` → **`warn`**；标题「每一个危险和可操作性问题**应**作为单项记录」→「……**宜**作为单项记录」；note 记录降级理由 |
| `HZ-002` | `severity: error` → **`warn`**；标题「工作表**应**能列出全部已分析节点」→「……**宜**能……」；note 记录降级理由 |
| 规则库头部 | 「可 error 的只有 6.6.3 与 6.6.4 这两类硬要求」**已改写**为「**本规则库没有任何 error 级规则**」，并写明理由 |
| 结果 | 本规则库**现有 0 条 error**；7 条规则为 6 warn + 1 info |

⚠️ **顺带更正了一处措辞**：标题里的"应"是把标准原文的"宜"写成了强制语气，
**标题本身就是判定语气的一部分**，故一并改为"宜"。

## 三、核对确认**成立**的三处规则库判断（本轮验证，非改动）

本规则库头部对三处边界做了保守处理，本次逐字核对**确认这些处理是对的**：

1. **附录 A.2 是资料性附录 ⇒ 不存在强制列清单。**
   原文：「表头中**可包括**下列信息……**也可记录其他信息**，如保护措施、严重程度、备注、风险等级等。」
   ⇒ 头部写的"工作表列标题用'可为'，且原文写明'也可记录其他信息'"**与原文一致**，缺列只能提示。
2. **标准未规定风险等级刻度。**
   6.5 只说风险分级"**是有用的**"，并把进一步论证**指向 IEC 60300-3-9**；
   ⇒ `HZ-005` 以 `institutional-configuration` 处理、`values` 出厂为空，**正确**。
3. **6.4.3 允许自定义引导词。**
   原文：「除上述引导词外，**还可使用对偏离的辨识更有利的其他引导词。只要在分析开始前进行了定义，就可以使用这些引导词。**」
   ⇒ `HZ-003` 只给 **warn**、并在 note 写明"使用表外引导词不必然不合规"，**与原文一致**。

**一处应予肯定的细节**：`HZ-003` 的 note 特意提示"国标用「**相反**」（不是'相逆'）、用「**异常**」对应英文 Other than"——
本次核对表 1 逐字确认**措辞无误**。

## 四、标准身份与效力（本轮核到的事实）

- 标准号 **GB/T 35320—2017**，英文名 *Hazard and operability studies (HAZOP studies) — Application guide*，
  **等同采用 IEC 61882:2001**（标识为 `GB/T 35320—2017/IEC 61882:2001`）。
- **2017-12-29 发布，2017-12-29 实施**（发布即实施）。
- **标准号为 GB/T ⇒ 推荐性国家标准**。
- 发布机构：国家质量监督检验检疫总局、国家标准化管理委员会。
- 提出：中国机械工业联合会；归口：全国电工电子可靠性与维修性标准化技术委员会（SAC/TC 24）、
  全国工业过程测量和控制标准化技术委员会（SAC/TC 124）。
- 结构：正文第 1～7 章 + **附录 A（资料性）报告方法** + **附录 B（资料性）HAZOP 示例**。
